# Advanced JavaScript Practical Assignment

## Overview

This project implements the six QuickCart practical exercises: objects and classes, array methods and collections, JSON handling, asynchronous JavaScript, performance and DOM events, and final integration.

## Technologies

- Modern JavaScript (ES6+)
- HTML5
- CSS3
- Node.js for console-based JavaScript files

## Project Structure

```text
quickcart-advanced-javascript/
├── part-a-objects-classes/products.js
├── part-b-array-methods/shopping-cart.js
├── part-c-json-debugging/json-handling.js
├── part-d-asynchronous/order-processing.js
├── part-e-optimization-events/index.html
├── part-e-optimization-events/script.js
├── part-e-optimization-events/style.css
├── part-f-integration/quickcart.js
└── README.md
```

## How to Run

Run each console exercise with Node.js:

```bash
node part-a-objects-classes/products.js
node part-b-array-methods/shopping-cart.js
node part-c-json-debugging/json-handling.js
node part-d-asynchronous/order-processing.js
node part-f-integration/quickcart.js
```

Open `part-e-optimization-events/index.html` in a browser, or serve the project with VS Code Live Server. Open browser developer tools to see scroll and memoization logs.

## Part Explanations

- **Part A:** Constructor prototypes, ES6 inheritance, destructuring, rest, spread, template literals, and arrow functions.
- **Part B:** `map`, `filter`, `reduce`, `forEach`, `Map`, `Set`, `freeze`, and `seal`.
- **Part C:** JSON serialization and parsing, plus output-based edge cases.
- **Part D:** Event loop behavior, callbacks, promises, async/await, and promise combinators.
- **Part E:** Debouncing, throttling, memoization, event bubbling, propagation, and event delegation.
- **Part F:** Integrated QuickCart order summary using all required ES6 concepts.
